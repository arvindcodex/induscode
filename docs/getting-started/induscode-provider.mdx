IndusCode (usage-billing) is the simplest way to get started with pay-as-you-go model access in IndusCode.

Instead of managing separate API keys across multiple vendors, you sign in once, add **IndusCode credits**, and select from available models directly in IndusCode.

If you want a flat monthly subscription that offers 2-5x the usage on selected open coding models compared to standard API rate, use [IndusCodePass](/getting-started/induscodepass) instead. IndusCodePass is a separate provider in IndusCode.

## Why use IndusCode (usage-billing)

- **Fastest setup**: no manual API key copy/paste; access to 100+ models supported by IndusCode
- **One account**: sign in once with Google, GitHub, or email
- **Pay as you go**: add IndusCode credits and use one balance across supported models
- **Free options**: look for models tagged **FREE** in the selector

## How it works

IndusCode (usage-billing) is the pay-as-you-go provider in IndusCode. Add IndusCode credits, then select **IndusCode** wherever you configure your provider.

- **IDE Extension**: Go to IDE extension settings, set **API Provider** to **IndusCode**, and sign in.
- **CLI**: Go to `/settings` and select **IndusCode** as your provider.

## Credits and usage

- Add **IndusCode credits** from your [IndusCode dashboard](https://app.induscode.bot/dashboard)
- Credits are used on a pay-as-you-go basis when you select paid models through IndusCode (usage-billing)
- View usage in IndusCode Settings → **View Usage**
- Switch organizations in IndusCode Settings → **Switch Organization**
