IndusCodePass is a low-cost monthly subscription — **$9.99/month** — that offers **2-5x the usage** on popular open coding models compared to standard API rate.

It's completely optional. You don't need IndusCodePass to use IndusCode, and you can always use any other provider alongside it.

## How it works

IndusCodePass is a separate provider in IndusCode. After subscribing, select **IndusCodePass** wherever you configure your provider.

- **IDE Extension**: Go to IDE extension settings, set **API Provider** to **IndusCodePass**, and sign in.

  <img src="/assets/induscodepass/induscodepass-ide-extension.png" alt="IndusCode IDE extension settings with IndusCodePass selected as the API Provider" />

- **CLI**: Go to `/settings` and select **IndusCodePass** as your provider.

## Why IndusCodePass

Open models have gotten really good. They now reach performance close to proprietary models for coding tasks, and because many providers can serve them competitively, they're usually far cheaper.

However, getting reliable access can be difficult. Providers vary in quality and availability, and standard rate limits can throttle heavy agentic workflows that read files, run commands, and iterate across many turns.

IndusCodePass solves this by:

- Curating a select group of open models tested and benchmarked for coding agent use
- Offering **2-5x the usage** on popular open coding models compared to standard API rate, so you can run long, complex agent tasks without interruption
- Providing stable access through IndusCode's infrastructure

<Note>
IndusCodePass is a separate provider from IndusCode (usage-billing). You can use both independently — subscribe to IndusCodePass for 2-5x the usage on popular open coding models compared to standard API rate, or use IndusCode (usage-billing) for pay-as-you-go access.
</Note>

## Using IndusCodePass outside of IndusCode

You can use IndusCodePass models from your own scripts, apps, or automation through the IndusCode API. The API uses the same OpenAI-compatible Chat Completions format as the rest of IndusCode's API.

To get started, create an API key from **Settings > API Keys** in [app.induscode.bot](https://app.induscode.bot). For the complete walkthrough, see the [IndusCode API Getting Started guide](/api/getting-started).

Use the full IndusCodePass model slug in the `model` field:

```bash
export INDUSCODE_API_KEY="your_api_key_here"

curl -X POST https://api.induscode.bot/api/v1/chat/completions \
  -H "Authorization: Bearer $INDUSCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "induscode-pass/qwen3.7-max",
    "messages": [
      {"role": "user", "content": "Write a TypeScript function that validates an email address."}
    ],
    "stream": false
  }'
```

## Usage

IndusCodePass measures usage against three limits:

- **5-hour rolling window** — your usage within rolling 5-hour period
- **Weekly** — your usage over the calendar week
- **Monthly** — your usage over the calendar month

To check your current usage, visit your [IndusCode dashboard](https://app.induscode.bot/dashboard/subscription?personal=true).
